# HomeAuction — запуск и управление

## Быстрый старт

- **Windows:** дважды нажмите `start.bat`. Откроются два терминала: локальный сервер Node.js и Cloudflare Tunnel. В окне Cloudflare будет временный публичный HTTPS-адрес для приглашения участников.
- **Linux / macOS:** `./start.sh` (нужны Bash, Node.js и npm).
- **Вручную:** `npm ci`, затем `npm start` (или `node server.js`) и в другом терминале `npm run tunnel` (или `npx cloudflared tunnel --url http://localhost:3000`).

Для автоматического старта нужен доступ к интернету: `npx` может скачать `cloudflared` при первом запуске. Если уже установлен системный `cloudflared`, можно использовать его напрямую. Локальный адрес — http://localhost:3000. Не размещайте публичную ссылку комнаты в открытом доступе: все вошедшие участники обладают игровым доступом, а первый вошедший становится ведущим.

## Управление

- **Размер колеса:** изначально большой режим, при этом все панели доступны. Кнопка «Свернуть/Развернуть» переключает большой и компактный размер. Выбор сохраняется в браузере.
- **Эффекты выбывания:** управление в верхней панели: «Эффекты ВКЛ/ВЫКЛ» и «Анимации выбывания» с галочками. Случайный эффект выбирается *локально на каждом клиенте* в момент выбывания. Если все галочки выключены или выключен общий переключатель, используется стандартное сворачивание (эффект 0). Звуки подчиняются общему переключателю «Звук»; звук стекла синтезируется без сторонних файлов.
- **Длительность:** ведущий может задать прокрутку от 2 до **500 секунд**. Измените длительность в настройках и нажмите «Применить настройки».
- **Сброс в пул:** оставляет лоты, сбрасывает ставки, готовность, историю и итог раундов; доступен, если колесо не вращается.
- **Очистить лоты и ставки:** стирает лоты и ставки, но оставляет участников и настройки; доступен между раундами.
- **Полный сброс комнаты:** сбрасывает настройки, игроков, лоты, очки, историю, победителя и даже текущее вращение. Все браузеры автоматически возвращаются на экран входа, при этом **Node.js и Cloudflare Tunnel не перезапускаются**. После сброса первый вошедший снова становится ведущим.

## Важно

Состояние комнаты хранится в оперативной памяти Node.js. После перезапуска процесса история, ставки и участники не сохраняются. Данные об очках других участников остаются скрыты до перехода к колесу; математический выбор победителя и механика выбывания находятся на сервере. Все новые визуальные эффекты не влияют на результат.

Шрифты подгружаются из Google Fonts, при недоступности сети используются системные запасные шрифты.
