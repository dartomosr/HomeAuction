# HomeAuction — анонимный аукцион на выбывание

HomeAuction — веб-приложение для проведения анонимного аукциона в реальном времени. Участники предлагают варианты, тайно распределяют между ними очки, а после готовности всех игроков ведущий запускает колесо на выбывание. Сервер отвечает за состояние комнаты и результат игры; браузер отображает интерфейс, колесо и визуальные эффекты.

## Быстрый старт

- **Windows:** запустите `start.bat`.
- **Linux / macOS:** выполните `./start.sh`.
- **Ручной запуск:** `npm ci && npm start` → откройте `http://localhost:3000`.

## Возможности

### Игровой процесс и пул

- Комната в реальном времени на Socket.IO: тайный пул вариантов и ставок, статусы готовности и переподключение по сохранённому токену.
- Стартовые пресеты комнат, настраиваемые лимиты слотов и добавление лотов сверх лимита с пометкой `+ ДОП`.
- Анонимные реакции `▲`/`▼` на чужие варианты; пул сортируется по рейтингу с плавной FLIP-анимацией.
- Настраиваемый резерв очков на чужие варианты и механика поддержки непопулярных лотов («Поддержка (до N очков)»).
- Режим зрителя: просмотр игры без ставок и добавления вариантов; роль сохраняется при переподключении.
- Удаление своего варианта, удаление чужого варианта и исключение игрока ведущим.

### Колесо на выбывание

- Колесо на Canvas с синхронным вращением у участников; шанс выбывания задаётся инвертированным весом (`1 / очки`).
- Объединение дубликатов перед первым вращением, запуск отдельных раундов и авто-крутка до определения победителя.
- Девятнадцать тем оформления, звуковой движок на Web Audio API и настраиваемые визуальные эффекты секторов.
- Настраиваемая длительность вращения, таблица вероятностей и история выбывания. Игровой результат определяется сервером, а не клиентскими эффектами.

### Аналитика и экспорт

- Окно «История» с вкладками «Все варианты» и «Статистика и графики»; в полном списке видны также нулевые и объединённые варианты и вкладчики.
- После финала кнопка «Результат» копирует готовую сводку матча для отправки в мессенджеры.

### Локальные сохранения (`.md` / `.txt`)

- Работа с папкой на ПК через File System Access API в поддерживаемых Chromium-браузерах и фоллбэк через выбор файла/скачивание.
- Три режима: стартовая база комнаты, личный пресет в пуле и полный слепок на колесе или после финала.
- Встроенная пошаговая памятка `?` для ведущего, участника и зрителя.
- Тема, звук и предпочтения эффектов сохраняются локально в браузере; доступны три варианта сброса комнаты.

## Локальные сохранения и пресеты

Файл сохранения — обычный текстовый `.md` или `.txt`. Его первая непустая строка должна быть ровно `==HOME AUCTION==`; файлы без этого маркера не распознаются. Каждый лот записывается на отдельной строке. Необязательные параметры после `|` задают неотрицательные очки и слот `ДОП`:

```markdown
==HOME AUCTION==
# Мой список фильмов
Интерстеллар
Дюна: Часть вторая | 20
Зеленая миля | 15 | ДОП
```

Варианты можно оформлять маркерами списка (`-`, `*`, `1.`), а комментарии и Markdown-заголовки после маркера сохранения игнорируются. При повторяющихся названиях в стартовом файле лоты объединяются, а очки суммируются.

До входа первого игрока сохранение загружается как стартовая база комнаты: ведущий становится автором лотов, стартовые очки учитываются в весе лота, но не списываются с бюджета игроков и базовые лоты не расходуют лимит обычных слотов. В фазе пула сохранение содержит только ваши лоты и ваши ставки; загрузка добавляет только новые названия с нулевыми очками, пропуская повторы и лоты, для которых не хватило слотов. На колесе и после финала файл содержит все варианты комнаты с итоговыми очками.

В поддерживаемых Chromium-браузерах можно выбрать папку: приложение отфильтрует в ней подходящие `.md`/`.txt` и сохранит новый файл непосредственно туда. В Firefox и Safari файл можно загрузить через выбор файла, а сохранение скачивается как `.md`.

## Требования

- Node.js и npm.
- Для внешнего доступа через Cloudflare Tunnel нужен интернет и доступ к Cloudflare.
- Сборщик фронтенда не используется. Сервер работает на CommonJS, браузер загружает нативные ES-модули.

## Запуск

### Windows: сервер и Cloudflare Tunnel в одном окне

1. Распакуйте весь проект в одну папку.
2. Запустите `start.bat`.
3. Откройте локальный адрес `http://localhost:3000`. Если туннель запустился, в консоли также появится временный HTTPS-адрес `trycloudflare.com`.
4. Чтобы остановить сервер и туннель, закройте окно запуска.

`start.bat` запускает `launch.ps1`, который управляет жизненным циклом сервера и Cloudflare Tunnel. Для этого способа запуска требуется Windows PowerShell.

### Linux / macOS: сервер и Cloudflare Tunnel

```bash
chmod +x start.sh
./start.sh
```

Скрипт проверяет Node.js/npm, при необходимости устанавливает npm-зависимости, запускает сервер и Cloudflare Tunnel. Для macOS может понадобиться современная версия Bash с поддержкой `wait -n`.

### Ручной запуск сервера

Установите зависимости и запустите приложение:

```bash
npm ci
npm start
```

Локальный сервер слушает порт `3000` по умолчанию. Для выбора другого порта задайте переменную окружения `PORT`.

Чтобы отдельно открыть приложение через Cloudflare Tunnel, в другом терминале выполните:

```bash
npx cloudflared tunnel --url http://localhost:3000
```

Временный адрес туннеля меняется при каждом запуске. Cloudflare Tunnel не требуется для использования приложения в локальной сети.

## Игровые правила

### Участники и варианты

- Первый вошедший в пустую комнату становится ведущим. Токен участника сохраняется в `localStorage`, чтобы восстановить его при переподключении.
- При входе в пустую комнату первый игрок (ведущий) может выбрать стартовый пресет правил: «Базовый», «Дипломатия» или «Хаос».

Стартовые значения пресетов из `src/config.js`:

| Пресет | Бюджет очков | Лимит вариантов | Резерв на чужие | Поддержка непопулярных | Реакции | `+ ДОП` |
|---|---:|---:|---|---|---|---|
| Базовый | 50 | 5 | Выключен | Выключена | Выключены | Только ведущему |
| Дипломатия | 50 | 5 | 25 очков | Выключена | Включены | Только ведущему |
| Хаос | 100 | 10 | Выключен | До 5 очков | Включены | Только ведущему |

Ведущий может менять параметры комнаты; значения в таблице — именно начальные настройки.

- При входе можно выбрать режим зрителя. Зритель видит пул и ход игры, но не может добавлять варианты, удалять их, распределять очки или отмечать готовность. Зрители не учитываются в счётчике готовности и не мешают переходу к колесу, когда готовы все активные игроки. Если в комнате есть только зрители, переход в `REVEAL` не выполняется.
- Зритель не может стать ведущим. Если действующий ведущий возвращается в комнату как зритель, права переходят первому активному игроку; если активных игроков нет, ведущего пока нет.
- При повторном входе с тем же токеном выбор роли из формы применяется к существующему участнику. При переходе в режим зрителя его готовность сбрасывается, а в фазе `POOL` его ставки очищаются.
- В фазе `POOL` каждый участник может создать до `maxItems` обычных вариантов. Варианты вне лимита добавляются отдельно с пометкой `+ ДОП` и не увеличивают счётчик обычных слотов. По умолчанию такие варианты доступны ведущему; ведущий может разрешить их всем.
- Автор может удалить свой вариант, пока не готов. Ведущий может удалить чужой вариант и исключить другого участника, если колесо не вращается.
- До перехода к колесу ставки других игроков скрыты. Когда все активные игроки готовы, пул раскрывается независимо от готовности зрителей. Если нет ни одного активного варианта, сервер возвращает игроков к состоянию ожидания и сообщает об этом.
- Ведущий может включить настройку «Реакции» (по умолчанию выключена). В фазе тайного пула игроки и зрители могут анонимно поставить или снять стрелку вверх/вниз на чужом варианте; оценивать собственный вариант нельзя. Включённые реакции сортируют список пула по рейтингу, а перемещение карточек анимируется.
- Ведущий может объединить два варианта до первого вращения. Ставки объединяются, а исходные варианты остаются в полном списке для просмотра.

### Очки и ставки

Значения по умолчанию: `maxPoints = 50` очков на участника и `maxItems = 5` обычных вариантов на участника.

- Каждый участник может распределить общий бюджет между своими и чужими вариантами. Общая сумма ставок не может превышать его бюджет.
- Если ведущий включает ограничение ставок на свои варианты, параметр `foreignOnlyPoints` задаёт резерв `R`: на собственные лоты можно потратить не более `N − R`, где `N` — бюджет участника. Резерв предназначен для ставок на чужие варианты; при этом общий расход всё равно не может превышать `N`.
- Например, при `N = 50` и `R = 20` на собственные варианты можно потратить не более 30 очков, а общий бюджет на все ставки остаётся равен 50.
- При уменьшении бюджета сервер корректирует ставки, которые перестают ему соответствовать, и снимает готовность с затронутых игроков.
- Поддержка непопулярных вариантов по умолчанию выключена: варианты с нулём очков не участвуют в колесе, но остаются доступны в полном списке. Если ведущий включает поддержку и задаёт порог `N` через `zeroItemWeight` (по умолчанию `0.5`), эффективные очки каждого варианта ниже `N` становятся равны `N`. Это гарантирует минимальный вес на колесе для вариантов, не набравших порог, и не позволяет микро-ставкам уменьшить этот вес.

### Колесо

- После перехода в `REVEAL` ведущий может объединить дубликаты и запускать отдельные раунды вращения.
- Сервер заранее фиксирует победителя с вероятностью, пропорциональной эффективным очкам варианта. В каждом раунде выбывает один из остальных вариантов; шанс выбывания и размер сектора пропорциональны обратному эффективному весу (`1 / очки`).
- Время вращения по умолчанию — `5.5` секунды. Ведущий может выбрать значение от 2 до 500 секунд с шагом 0.5. Участники видят текущую настройку.
- Авто-крутка запускает следующие раунды до определения победителя и ожидает завершения эффекта выбывания перед следующей прокруткой.
- Выбор эффектов выбывания и их общий переключатель — локальные настройки браузера, поэтому визуальная анимация у разных зрителей может отличаться. Игровой исход от этого не зависит.
- Помимо звуков колеса и победы, интерфейс воспроизводит мягкий клик при добавлении лота и на основных кнопках, тихий тик при изменении ставок (с защитой от частых повторов), а также сигналы при переключении готовности и появлении уведомлений. Все звуки управляются общим переключателем звука в шапке.
- Кнопка «История» открывает единое окно с двумя вкладками: «Все варианты» показывает полный расклад по лотам и вкладчикам, а «Статистика и графики» разблокируется после определения победителя. Аналитика включает итоги матча, вклад в победный вариант, КПД очковых вложений по владельцам лотов, график изменения шансов победы каждого варианта по раундам, индекс точности ставок (ранние выбывания против финалистов) и выживаемость вариантов.
- При системной настройке `prefers-reduced-motion` сложные анимации пропускаются.

### Сброс комнаты

- **Сбросить в пул**: сохранить варианты, очистить ставки и результаты текущей игры.
- **Очистить лоты и ставки**: сохранить участников и настройки, удалить все варианты и начать заново.
- **Полный сброс комнаты**: очистить участников, варианты, очки, историю и настройки. Все подключённые игроки возвращаются на экран входа; сервер и туннель продолжают работать.

├── src/wheel-math.js       выбор победителя и выбывающего варианта
└── src/socket-handlers.js  Socket.IO-события и рассылка состояния

public/
├── index.html              разметка; js/wheel-effects.js загружается перед модулем приложения
├── style.css               последовательность CSS @import
├── css/
│   ├── themes.css           переменные девятнадцати тем
│   ├── base.css             базовые элементы и общий сброс
│   ├── pool.css             вход, пул и боковая панель
│   ├── wheel.css            экран колеса и эффекты
│   └── modal.css            модальное окно и уведомления
└── js/
    ├── package.json          контекст ES-модулей для проверки Node.js
    ├── constants.js          палитры, сообщения прокрутки и список эффектов
    ├── store.js              общее состояние браузера и доступ к localStorage
    ├── dom.js                ссылки на DOM-элементы и Canvas-контексты
    ├── audio.js              Web Audio API и звуки эффектов
    ├── wheel-canvas.js       отрисовка, вращение и визуализация выбывания
    ├── wheel-effects.js      классический Canvas-движок эффектов сектора
    ├── save-parser.js        парсинг и сериализация .md с маркером ==HOME AUCTION==
    ├── saves.js              локальная папка, импорт и экспорт сохранений
    ├── ui-modals.js          окна истории, статистики, графиков, справки и копирования итогов
    ├── ui-notifications.js   всплывающие уведомления (тосты)
    ├── ui-render.js          отрисовка входа, сайдбара, пула и экрана колеса
    ├── socket-client.js      Socket.IO-клиент и обработка входящих событий
    └── main.js               точка входа и обработчики действий пользователя

### Сервер

- `server.js` создаёт Express-приложение, HTTP-сервер и Socket.IO, отдаёт каталог `public` и запускает сервер.
- `src/config.js` экспортирует `DEFAULT_SETTINGS`, `ROOM_PRESETS` и `generateId()`.
- `src/state.js` содержит состояние одной комнаты, расчёт очков, активных лотов и `buildClientState(forToken)`, а также функции стартовой загрузки `addInitialItems` и внутриигрового импорта `importPoolItems`. В фазе `POOL` каждому участнику отправляется персональное состояние без чужих ставок.
- `src/wheel-math.js` содержит алгоритмы выбора заранее определённого победителя и кандидата на выбывание.
- `src/socket-handlers.js` регистрирует обработчики соединений и игровых событий, управляет таймером вращения и рассылает обновления.

Серверная часть использует CommonJS (`require` / `module.exports`). Состояние хранится в памяти процесса и не сохраняется между перезапусками.

### Браузер

- `public/index.html` подключает Socket.IO-клиент, затем классический скрипт `<script src="js/wheel-effects.js">`, затем точку входа `js/main.js` как `<script type="module">`.
- `public/icon.webp` используется как иконка сайта (favicon) во вкладке браузера.
- ES-модули используют относительные импорты браузера. Сборщик или этап компиляции не нужен.
- Изменяемые данные приложения (игровое состояние, токен, тема, звук, режим зрителя, авто-крутка и параметры анимации) хранятся в одном объекте `store` из `public/js/store.js`.
- `public/js/save-parser.js` разбирает и сериализует формат `.md` с маркером `==HOME AUCTION==`; `saves.js` управляет локальной папкой через `showDirectoryPicker`, а также импортом и экспортом файлов.
- `public/js/ui-render.js` отрисовывает основной экран: вход, сайдбар, пул и экран колеса. Модальные окна истории, статистики, графиков, справки и копирования итогов вынесены в `ui-modals.js`; тосты — в `ui-notifications.js`.
- Все ссылки на DOM объявлены в `public/js/dom.js`. UI-модули отправляют команды через Socket.IO-клиент из `store`, не создавая циклические импорты между отображением и транспортом.
- `public/style.css` содержит только импорты пяти CSS-файлов в порядке: темы, базовые стили, пул, колесо, модальные элементы.
- `public/js/wheel-effects.js` остаётся отдельным классическим скриптом: он объявляет `window.WheelSectorEffects`, который создаётся модулем `dom.js`.

## Проверки и диагностика

Запустите быструю автоматическую проверку проекта:

```bash
npm test
```

Набор `tests/smoke.test.js` включает 14 автотестов на встроенных `node:test` и `node:assert/strict`. Проверяются синтаксис JavaScript, DOM-контракт и CSS, механика «Поддержки», пресеты комнат, реакции, парсер `.md`-сохранений, сценарии стартовой загрузки и внутриигрового импорта лотов, а также выбор в колесе. Дополнительные зависимости для запуска тестов не требуются.

Если страница не открывается, проверьте, что Node.js и npm доступны в `PATH`, зависимости установлены (`npm ci`), а порт `3000` не занят. Если локальная страница работает, но внешний адрес не появился, проверьте интернет-соединение и доступность Cloudflare: туннель запускается отдельно от Express-сервера.

## Ограничения и безопасность

- Приложение поддерживает одну комнату на один процесс сервера. Игровое состояние находится в оперативной памяти; база данных и постоянное серверное хранилище не используются.
- Токен в `localStorage` позволяет восстановить участника, но не является полноценной парольной аутентификацией.
- Первый участник пустой комнаты получает права ведущего. Любой, у кого есть ссылка на открытую комнату, может попытаться присоединиться; распространяйте ссылку только среди участников.
- Серверная сторона проверяет игровые права и остаётся источником истины. Клиентские проверки предназначены для интерфейса и не заменяют серверную авторизацию.
- Express сам не настраивает внешнюю TLS-терминацию. Публичный HTTPS-адрес в рекомендуемом сценарии предоставляет Cloudflare Tunnel.
- Шрифты загружаются с Google Fonts; при отсутствии доступа используются запасные системные шрифты.
